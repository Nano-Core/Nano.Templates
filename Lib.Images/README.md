# Lib.Images

> _Library for resizing and manipulating images._  

***

## Table of Contents
* [Summary](#summary)

## Summary
This library contains a set of extension methods for working with image streams, providing functionality for resizing, processing, and managing image data. It is built on top of 
`SkiaSharp` and supports efficient image manipulation while preserving aspect ratio, transparency, and image quality.

The library also includes helper methods for handling stream operations, such as saving processed images directly to files. These extensions simplify common image-related tasks by 
providing reusable, stream-based functionality that can be easily integrated into applications requiring image processing capabilities.
